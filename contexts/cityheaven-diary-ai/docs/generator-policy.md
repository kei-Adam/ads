# 7種の日記生成仕様

## 共通ルール
本人同意済みの言葉遣い、写真、確認済み事実に限り、タイトル候補3案・本文候補2案・画像加工案1案を出す。第三者のランキング日記は一般的な構成だけ参考とし、複製しない。日時・待機・予約・接客・人気・ランキング・動画公開を推測で書かない。日記1本につき目的とCTAを1つ。本人生前承認なしの公開禁止。

| type | 目的 | 必須条件 |
|---|---|---|
| morning | 親近感 | 本人の口調・事実としての近況。出勤を勝手に書かない |
| clock_in | 当日予約 | 出勤確定と出勤実績。空き枠も確認済みのみ |
| clock_out | 関係維持 | 退勤確定。次回出勤は確定分のみ |
| thank_you | 再訪 | 実際の接客確認と本人が公開許可した話題。顧客情報禁止 |
| mygirl_video | 限定視聴 | 公開済み動画・公開範囲確認。事前予告は更新済みとしない |
| freepost | 24時間の再訪 | 素材・公開状態確認。口コミお礼日記として投稿不可 |
| waiting | 直近予約 | 現在の待機/空き枠を5分以内に再確認（初期ルール） |

## 出力
title_candidates[], body_candidates[], image_edit_plan, intent, cta, visibility, post_mode, publishable, missing_verified_fields[], review_notes[], verified_sources[]。

本人承認前はpublishable=falseまたは公開操作禁止。公開範囲は公開後変更不可。フリーポス/限定/予約/動画/口コミお礼は通常メール投稿と区別する。事実不明ならmissing_verified_fieldsに記録して確認を求める。品質テストは7種×10件+20%の例外ケース以上。
