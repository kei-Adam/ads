# Ads 写メ日記AI｜コンテンツ活用・予約・写真加工 統合レポート v2.0
2026-11-09 / Official specifications verified, conversion effect unvalidated

## 要約
キャスト本人向け月額サービス。1投稿で写真を選び加工し文章を作るのに約30分かかる負担を、本人の写真＋一言→写真自動補正→タイトル3案＋本文2案→本人承認で5分以内、挑戦3分以内に短縮する。投稿数増加だけでなく、WEB予約成立件数・増加率を主要KPIとする。

## 指標の違い
インフルエンサーレベルは公式SS〜Cの指標。希望する「80点」はAds内の目標として扱い、公式配点との換算は未確認。
「WEB予約人気」の星は前月のWEB予約実績ベースで、星の閾値は非公開。星の増加を保証しない。
増加率=(当期WEB予約成立-基準期)/基準期×100。基準期0件なら率は出さず、0→N件と表示。

## 写真の選定・加工仮説
- おはよう: 朝の私服、手元、飲み物。柔らかな露出・暖色・自然さ→親近感。
- 出勤したよ: 当日の私服コーデ/メイク後の写真。9:16で顔・服が切れないよう調整、背景整理→出勤認知・予約。
- 退勤したよ: 当日の別カット、夜の私服や小物。暗所ノイズ、背景の私物/場所特定要素を除去→次回への興味。
- お礼: 本人の当日写真/花・小物。個人情報/顧客情報を削除し、自然な色調に→再訪。
- マイガール動画: 本人の動画から切り出した表紙。縦カバー・短い文字・プレビューの見え方をチェック→限定閲覧。
- フリーポス: 当日のスナップ。鮮度・1テーマ・文字過多防止→24時間再訪。
- 待機中: 現在の服装に近い写真。背景の位置情報を削除→直近予約。

この画像カテゴリの比較効果は**未検証の仮説**であり、3都市ランキング掲載者の写真別予約効果を測定したものではない。収集したランキングは2026-07-20号の8名の公開投稿に基づく質的研究。

## 媒体の検証済みルール
通常静止画像: 1投稿1枚、1080×1920、9:16、10MB以下。フリーポスは24時間で削除、お礼日記との併用不可。限定/動画/フリーポス/予約投稿はメール投稿対象外。公開範囲は投稿後変更不可。具体的な公式URLは research/official-sources.md。

## 30日実験
同意済みキャスト10〜15名。7日記種類×10ケース＋20%例外の生成テスト。
初期と導入後の出勤日数、WEB予約、日記数、マイガール登録、投稿完了率、制作時間を比較。予約は季節性・販促等の影響を区別。
作業時間: 最低10分、目標5分、挑戦3分。公開達成率: 最低90%、目標98%。重大な誤り0件。投稿能力に120%の余裕。
元完売嬢監修は本人らしい口調と写真の一致、店舗管理者は出勤/予約/媒体の事実、マーケティング担当は予約指標の評価を担当。

## 実装
写真選択→自然補正→タイトル/本文生成→承認→保存/本人投稿のMVPから開始。姫デコの外部API・統計取得・自動投稿は提供/許諾可否が未確認のため、確認前に連動稼働を約束しない。個人画像、顧客・予約データは非公開で別管理。
