# Ads 写メ日記AI｜初期コンテキスト v2.0
作成日 2026-11-09 / 初期調査・成果未検証

## 目的
キャスト個人向け月額サービス。1投稿の写真選択・加工・文章・投稿準備に約30分かかるという課題を解決し、中央値5分、チャレンジ3分以内を目指す。コンテンツ活用度80点（Ads目標）とWEB予約の増加を重視。予約増を保証しない。

## データ優先順位
1. 本人が明示的に承認した文章・写真・事実
2. 権限を持って確認した最新の出勤/空き枠/予約情報
3. 媒体公式仕様
4. 公開ランキングの文章から抽象化した汎用構成（全文複製・画像転載は禁止）

## コンテキスト
- docs/strategy-and-kpis.md : 予約・コンテンツ活用の評価
- docs/photo-playbook.md : 写真素材/加工/禁止事項
- docs/generator-policy.md : 7種類の日記生成
- docs/mvp-roadmap.md : 開発・同意・姫デコ連携
- research/ranking-notes-anonymized.md : 3都市の公開投稿の質的観察
- research/official-sources.md : 公式URLと検証状態

このリポジトリは公開。実際の顔写真、顧客/予約データ、認証情報、APIキーは保存禁止。実運用データは別の非公開・アクセス制御環境へ。
