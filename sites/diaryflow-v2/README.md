# Ads DiaryFlow — LP v2 (prototype)

前回の「ふわり日記」LPの再設計版。ブランド名は仮称。
主な差別化: キャスト個人向けの「画像加工→文章生成→姫デコ・他媒体向け投稿準備→マイガール育成→WEB予約検証」。
女性向けの抑えたピンク、黒に近い文字色、プロダクトUIを主役にしたレスポンシブ構成。

## 実装済み（LPのみ）
- スマホ対応サイト、7種類の日記サンプル切替、FAQ、スマホメニュー
- 姫デコ同時投稿の対象/非対象マトリクス、媒体別フローの説明
- インフルエンサー活用度80点（Ads目標）と予約KPIの説明
- 先行案内の公式LINE導線

## サービスとしては開発前・未提供
実AI生成、画像アップロード/加工、姫デコの自動投稿・API連携、他媒体の同期、予約データ集計、サブスク決済、元完売嬢の正式監修体制。

## プレビュー
index.html は CSS/JS内蔵の単一ファイル版。ブラウザから開けます。

## 重要なルール
姫デコの公式同時投稿はAdsの連携機能ではありません。通常日記等に限り、限定/動画/フリーポス/口コミお礼は非対象。別媒体では予約リンクが機能しないことがあり、編集・削除は同期されません。連携の可否は利用許可と公式仕様確認を条件とします。
