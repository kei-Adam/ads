# ふわり日記（仮称） by Ads — 女性向け先行案内ホームページ

ピンク・アイボリー・白でデザインした、キャスト個人向け写メ日記支援サービスの**開発中・先行案内用LP**です。競合サイトを分析した上で、スマートフォンから閲覧しやすい構成にしています。

## ファイル
- `index.html`: セマンティックHTML / ページ構成
- `styles.css`: レスポンシブデザイン / オリジナルの図版表現
- `main.js`: 日記タイプの切り替え、サンプル生成、コピー、写真加工比較、スマホメニュー
- `research/competitor-audit-2026-11-09.md`: 5社競合・構成の根拠
- `preview_desktop.png`, `preview_mobile.png`: 作成したプレビューの全画面キャプチャ

## 起動方法
`index.html` をブラウザで開く。別途サーバー・APIキー・依存ライブラリは必要ありません。Webホスティングでは3ファイルを同じフォルダで公開してください。

## 現在の実装範囲
- ✅ レスポンシブLP、静的なオリジナル人物イラスト（SVG）、7種類の日記案内
- ✅ 動作する文章サンプル（**定型文デモ**。実際のAIモデルではありません）
- ✅ 写真の補正イメージを比較するスライダー（イラストを使った表示例）
- ✅ LINEへのお問い合わせリンク：`https://lin.ee/7hdDDlN`
- ✅ FAQ、料金案、プライバシー方針、開発中表記
- ❌ 本物のAI生成、写真のアップロード/加工、画像保管、姫デコAPI連携、決済、会員管理、予約分析は未実装
